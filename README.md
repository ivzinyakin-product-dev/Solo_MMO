Браузерная одиночная RPG с механикой непрерывной авто-охоты (Camp FSM), исследованием 10 детализированных зон и глубокой ролевой системой по канонам легендарной **Ragnarok Online**. Проект объединяет классическую механику RO (полное древо 2-х профессий, формулы статов STR/AGI/VIT/INT/DEX/LUK, карты монстров, заточку экипировки с процедурным сиянием до +10, мировых MVP-боссов и кузнечное дело T1–T5) с процедурной векторной чиби-графикой на движке **PixiJS**.

## 🌟 Ключевые игровые системы

### 1. 🧙 Классическая ролевая система Ragnarok Online
* **Древо профессий (Job Tree)**:
  * **Новичок (Novice, Tier 0)**: Стартовый класс с базовыми навыками выживания и обращением с любым оружием.
  * **1-я Профессия (Tier 1)** — доступна при достижении 10 Job Lv:
    * 🗡️ **Мечник (Swordsman)**: Мастер клинка, мощный Magnum Break, высокий запас HP и физическая защита.
    * 🏹 **Лучник (Archer)**: Дальнобойный стрелок, Double Strafe, Arrow Shower, расчет урона от DEX.
    * 🧙‍♂️ **Маг (Mage)**: Властитель стихий, Fire Bolt, Cold Bolt, Lightning Bolt, урон от INT.
    * ✝️ **Аколит (Acolyte)**: Священный воин, Heal, Increase AGI, Blessing, Holy Light.
  * **2-я Профессия (Tier 2)** — доступна при развитии 1-й профессии:
    * 🛡️ **Рыцарь (Knight)**: Элитный кавалерист, сокрушительный размах *Bowling Bash* и пронзающий *Spiral Pierce*.
    * ⛨ **Крестоносец (Crusader)**: Несокрушимый паладин со щитом, *Зеркальный Щит (Shield Mirror)* и карающий *Великий Крест (Grand Cross)*.
    * 🦅 **Охотник (Hunter)**: Повелитель верного боевого **Сокола (Falcon Companion)**, стремительный *Blitz Beat* и капканы.
    * 🎵 **Бард (Bard)**: Менестрель и снайпер, поддерживающие боевые песни-ауры (*Поэма Браги*), снижающие кулдаун умений.
    * 🔮 **Волшебник (Wizard)**: Архимаг катастрофических разрушений: *Метеоритный дождь (Meteor Storm)*, буран *Frost Diver*.
    * 📖 **Мудрец (Sage)**: Боевой кастер, авто-каст заклинаний при ударах оружием (*Hindsight*).
    * 🕊️ **Прист (Priest)**: Верховный жрец, защитный барьер *Kyrie Eleison*, святилище *Sanctuary* и *Magnus Exorcismus*.
    * 👊 **Монах (Monk)**: Мастер рукопашных комбо и Духовных Сфер (Spirit Spheres), легендарный *Удар Азуры (Asura Strike / Guillotine Fist)*.

* **Классические атрибуты и вторичные статы**:
  * **STR**: Физическая атака (ATK) ближнего боя, переносимый вес.
  * **AGI**: Скорость атаки (ASPD) и параметр уклонения (FLEE).
  * **VIT**: Максимальное HP, защита (DEF) и регенерация здоровья.
  * **INT**: Магическая атака (MATK), максимальное SP и регенерация маны.
  * **DEX**: Меткость (HIT), минимальный разброс урона, скорость каста, сила лучников.
  * **LUK**: Шанс критического удара (CRIT, игнорирующий броню) и удача.
* **Каноничные формулы**: Реализована механика штрафов разницы уровней по опыту, проверка попадания (HIT vs FLEE), снижение урона в процентах и единицах.

### 2. ⚔️ Плавная авто-охота по поляне и поиск пути (Camp FSM)
* **Передвижение по поляне (Meadow Roaming)**:
  * Включение/выключение авто-боя одной круглой кнопкой `⚔️` в правом нижнем углу экрана.
  * Вместо статического ожидания персонаж непрерывно и плавно патрулирует локацию от моба к мобу.
* **3-уровневый интеллектуальный выбор цели**:
  1. *Агрессивные мобы*: Приоритетная защита от мобов, атакующих героя (с проверкой Raycast прямой видимости).
  2. *Ресурсные жилы и травы*: Автоматический подход и сбор медных, железных, серебряных жил и лечебных растений в радиусе видимости.
  3. *Ближайшие цели*: Выбор оптимального монстра с учётом препятствий и дистанции атаки.
  4. *Патрулирование*: Плавный обход поляны при ожидании респавна монстров.
* **Интеллектуальная навигация (Visibility Graph + A*)**:
  * Расчёт кратчайшего пути с обходом домов, фонтанов, деревьев и скал.
  * Сглаживание траектории (Raycast String-Pulling) и скольжение вдоль коллизий (Sliding Collision).
  * Встроенный сторожевой таймер (Unstuck Watchdog) предотвращает застревания персонажа.
* **Магнетизм трофеев**: Выпадающий лут и Zeny плавно притягиваются к герою при авто-охоте.

### 3. 🗺️ Мир Мидгарда: 10 детальных зон и MVP-боссы

Мир разбит на открытые локации со своими монстрами, ресурсами и музыкально-визуальным стилем:

1. 🏡 **Деревня Новичков (zone_village)** — Безопасный центральный хаб: фонтан, NPC-лавочник, кузница мастера Бранда, порталы.
2. 🌸 **Цветочные Поля (zone_meadow, Ур. 1–5)** — Поринги, Фабре, Лунатики.  
   👑 *MVP-боссы*: **Золотой Жук (Golden Bug)** и **Король Порингов (Poring King)**.
3. 🌲 **Густой Лес Пайон (zone_forest, Ур. 6–12)** — Споры, Ядовитые споры, Волки, Древесные Ивы.  
   👑 *MVP-босс*: **Вожак Волков (Wolf Leader)**.
4. 🌊 **Затонувшие Руины (zone_sunken_ruins, Ур. 13–18)** — Рода-лягушки, Гидры, Вадоны, Страж Шлюза.  
   👑 *MVP-босс*: **Лорд Дрейк (MVP Drake)**.
5. 🏜️ **Муравьиный Каньон (zone_ant_canyon, Ур. 19–23)** — Скорпионы, Муравьи Андре, Песчаные Големы, Центурионы.  
   👑 *MVP-босс*: **Королева Майя (Maya Queen)**.
6. 🏰 **Горная Цитадель Альдебаран (zone_high_city, Ур. 24+)** — Высотный город-хаб с быстрыми перелётами и развитой торговлей.
7. ⚔️ **Орочья Крепость (zone_orc_fortress, Ур. 24–30)** — Орки-воины, Орки-лучники, Шаманы, Военачальники.  
   👑 *MVP-босс*: **Орочий Лорд (Orc Lord)**.
8. ⛪ **Проклятое Аббатство (zone_cursed_abbey, Ур. 31–38)** — Скелеты-рыцари, Шепчущие призраки, Мимики, Палачи.  
   👑 *MVP-босс*: **Тёмный Лорд (Dark Lord)**.
9. 🕰️ **Часовая Башня (zone_clock_tower, Ур. 39–45)** — Панки, Алярмы, Батори, Хранители Времени.  
   👑 *MVP-босс*: **Рыцарь Бури (Stormy Knight)**.
10. 🌋 **Вулканический Кратер (zone_dragon_volcano, Ур. 46–50)** — Кахо, Дракониды, Петиты, Ферусы.  
    👑 *Финальный MVP*: **Владыка Огня Ифрит (Ifrit)**.

### 4. ⚒️ Кузница мастера Бранда: Ковка, Заточка и Синтез

* **Строгая градация ковки по тирам (Т1–Т5)**:
  * **Тир 1 (Медный)**: Мечи Новичка, Ученические Луки, Посохи, Тканевые капюшоны, Кожаные куртки, а также базовые образцы из железной руды (Короткий меч, Кинжал, Дубина).
  * **Тир 2 (Железный)**: Палаши, Охотничьи луки, Жезлы чародея, Кольчуги, Сапоги странника, Железные кольца.
  * **Тир 3 (Серебряный)**: Двуручные клинки, Композитные луки, Серебряные жезлы, Латные доспехи, Серебряные перстни.
  * **Тир 4 (Золотой)**: Клейморы, Луки ветров, Гримуары стихий, Золотые кирасы, Золотые амулеты.
  * **Тир 5 (Платиновый)**: Мечи правосудия, Луки ярости, Королевские скипетры, Доспехи титана, Платиновые перстни.
* **Бижутерия с характеристиками**: Кольца, перстни и амулеты дают точные числовые бонусы к STR, AGI, INT, DEX, VIT, LUK, HP/SP и шансу критического удара.
* **Заточка экипировки (+1 .. +10)**:
  * Безопасная заточка до +4 (100% шанс).
  * Заточка +5..+10 с шансом поломки или использованием камней защиты.
  * **Динамическое сияние заточки**: при заточке на +7..+10 оружие получает визуальное свечение (клинковые ауры для мечей, световая тетива для луков, парящие магические сферы для посохов).
* **Синтез и переплавка руд**:
  * Медь ➔ Железо ➔ Серебро ➔ Золото ➔ Платина, а также самоцветы, Оридекон и Элуниум.
* **Извлечение карт**: Безопасное снятие инкрустированных карт из гнезд экипировки.

### 5. 🎴 Карты монстров и слоты экипировки
* Каждый убитый монстр имеет шанс оставить свою именную карту.
* Вставка карт в свободные слоты оружия, щитов, доспехов и аксессуаров.
* Процентные модификаторы урона по типам врагов, прибавки к базовым характеристикам и пассивные триггеры.

---

### 6. 📜 Квесты, Доска заказов и Бестиарий
* **Журнал квестов**: Сюжетные поручения, заказы на уничтожение мобов и сбор ингредиентов.
* **Quest Tracker**: Компактный виджет текущих задач на экране справа под радаром.
* **Элитные контракты (Elite Bounty)**: Охота на усиленных редких вожаков за солидные награды.
* **Книга приключений (Бестиарий)**: Полная статистика по всем видам монстров, их слабостям, шансам выпадения трофеев и прогрессу коллекции карт.

---

### 7. 🎨 Процедурная графика и анимации (PixiJS)
* Векторный процедурный рендеринг:
  * Процедурная физика чиби-персонажей: шаг, инерция при беге, замах оружия, прыжки.
  * Специальная 4-фазная физика порингов: сжатие перед толчком, дуговой полет с динамической тенью и растекание при приземлении.
  * Визуальное отображение надетого оружия, головных уборов и экипировки.

## 🎮 Управление и горячие клавиши

| Клавиша / Действие | Функция |
| :--- | :--- |
| **Клик ЛКМ по земле** | Перемещение персонажа в указанную точку |
| **Клик ЛКМ по мобу / жиле** | Выбор цели, атака или начало добычи ресурса |
| **Кнопка `⚔️` (справа внизу)** | Включение / выключение режима авто-охоты (Camp FSM) |
| **`C` / `С` (рус)** | Окно характеристик персонажа (Stats Window) |
| **`I` / `B` / `Ш` / `И` (рус)** | Рюкзак и окно экипировки (Inventory) |
| **`M` / `Ь` (рус)** | Интерактивная карта мира с телепортами (World Map) |
| **`1` .. `5` / `Q` `W` `E` `R` `Space` | Горячие слоты панели навыков (Skill Hotbar) |
| **`ESC`** | Закрыть все открытые модальные окна |
| **Кнопка 🦋 вверху** | Мгновенный телепорт в Деревню Новичков (Крыло Бабочки) |
| **Кнопка 🏰 вверху** | Быстрый переход в Горную Цитадель Альдебаран (с 24 уровня) |

## 🚀 Быстрый старт

### Требования
* [Node.js](https://nodejs.org/) версии 18 или новее
* Пакетный менеджер `npm`

### Запуск проекта

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/<your-username>/solo-mmo-midgard-camp.git
   cd solo-mmo-midgard-camp
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите режим разработки**:
   ```bash
   npm run dev
   ```
   *Или дважды кликните `start.bat` на Windows.*  
   Игра откроется по адресу `http://localhost:3000` (или `5173`).

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   Оптимизированный билд создаётся в папке `dist/`.

## 📦 Автоматическое управление релизами

Проект оснащён сквозной системой управления версиями и релизами:

* **Автоматически при заливке на GitHub**:
  При пуше изменений в ветку `main` GitHub Actions (`.github/workflows/release.yml`) автоматически определяет изменение версии в `package.json`, проставляет Git-тег, собирает zip-архив с игрой и публикует релиз во вкладке **Releases**.
* **Локальный скрипт запуска**:
  Двойной клик по **`release.bat`** (или запуск `npm run release`) позволяет вручную проверить сборку, выбрать патч/минор версию и автоматически отправить релиз на GitHub.
