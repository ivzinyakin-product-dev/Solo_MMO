Браузерная одиночная RPG с механикой авто-охоты (Camp FSM), исследованием открытых зон и глубокой ролевой системой по мотивам культовой **Ragnarok Online**. Игра сочетает в себе классические механики (классы, статы, карточки монстров, заточку до +10, MVP-боссов, крафт у кузнеца) и процедурную чиби-графику на **PixiJS**.

---

## 🌟 Основные особенности

### 1. 🧙 Классическая ролевая система Ragnarok Online
* **Древо профессий**: Начинайте путь Новичком (*Novice*) и выбирайте профессию после достижения 10 Job Lv:
  * 🗡️ **Мечник (Swordsman)** ➔ **Рыцарь (Knight)**
  * 🏹 **Лучник (Archer)** ➔ **Охотник (Hunter)**
  * 🪄 **Маг (Mage)** ➔ **Волшебник (Wizard)**
  * 🔨 **Послушник (Acolyte)** ➔ **Священник (Priest)**
  * 🗡️ **Вор (Thief)** ➔ **Убийца (Assassin)**
* **Классические атрибуты**:
  * **STR**: Физическая атака (ATK), вес.
  * **AGI**: Скорость атаки (ASPD), уворот (FLEE).
  * **VIT**: Максимальное HP, защита (DEF), естественная регенерация HP.
  * **INT**: Магическая атака (MATK), максимальное SP, регенерация SP.
  * **DEX**: Меткость (HIT), минимальный урон, скорость каста, сила лучников.
  * **LUK**: Шанс критического удара (CRIT), удача.
* **Формулы RO**: Полная реализация механик расчёта урона, меткости (HIT vs FLEE), снижения брони DEF/MDEF и критических ударов.

### 2. 🔥 Авто-охота и поиск пути (Camp FSM)
* **Плавное патрулирование**: Персонаж автоматически перемещается по поляне от цели к цели, атакует подходящих мобов и собирает ценные ресурсы (руду, травы).
* **Интеллектуальная навигация (Visibility Graph + A*)**:
  * Алгоритм поиска пути с обходом препятствий и сглаживанием траектории (Raycast String-Pulling).
  * Плавное скольжение вдоль стен и коллизий (Sliding Collision & Tangent Deflection).
  * Сторожевой таймер от застреваний (Unstuck Watchdog).
* **Авто-зелья и авто-ротация**:
  * Использование лечебных зелий при падении здоровья ниже настраиваемого порога.
  * Ротация активных умений с проверкой дистанции, кулдаунов и доступного SP.

### 3. 🗺️ Живой мир и зоны охоты
* **Зоны**:
  * 🏡 **Деревня Новичков** (Безопасная зона, регенерация сил, NPC-торговцы, кузнец).
  * 🌿 **Изумрудная Поляна** (Тир 1, Поринги, Фабре, Лунатики).
  * 🍄 **Грибной Лес** (Тир 2, Споры, Ядовитые споры, Волки).
  * 🏛️ **Затопленные Руины** (Тир 3, Скелеты, Зомби, Призраки).
  * ⛰️ **Каньон и Вулканические пещеры** (Тир 4–5).
* **MVP-боссы и Вожаки**:
  * Спавн элитных вожаков со свитой миньонов.
  * Грозные мировые MVP-боссы (*Король Порингов*, *Лорд Дрейк* и др.) с таймерами возрождения, сокрушительными ударами и телеграфом атак на земле.

### 4. ⚒️ Кузница, крафт и заточка
* **Ковка снаряжения (Тиры 1–5)**:
  * Полный комплект экипировки: оружие (мечи, луки, жезлы, булавы), щиты, колчаны, гримуары, шлемы, доспехи, накидки, сапоги, кольца и амулеты.
  * **3 ступени качества**:
    * ⚒️ *Походный* (Базовые характеристики, 0–1 сокет).
    * ✨ *Мастерский* (+20% к статам, 1–2 сокета).
    * 🌟 *Реликвия* (+45% к статам, до 4 сокетов, уникальное свойство реликвии).
* **Заточка снаряжения (+1 .. +10)**:
  * Безопасный лимит заточки до +4.
  * Прогрессирующие шансы успеха и использование благословенных камней для защиты от сгорания.
  * **Динамическое сияние заточки**: при заточке на +7..+10 оружие начинает мерцать процедурным сиянием (радиальные клинковые волны для мечей, световая дуга натяжения для луков, магические сферы для жезлов и пульсация для булав).
* **Переплавка руд**: Медь ➔ Железо ➔ Фракон ➔ Оридекон / Элуниум.

### 5. 🎴 Карты монстров
* Каждый монстр имеет шанс дропнуть свою персональную карту.
* Инкрустация карт в свободные слоты экипировки для получения мощных пассивных эффектов, процентных прибавок к урону, защите и атрибутам.

### 6. 🎨 Процедурная чиби-графика (PixiJS)
* Полностью векторный рендеринг без внешних тяжёлых спрайтшитов:
  * Процедурные тела, волосы, глаза, броня и оружие.
  * Реалистичная физика чиби-анимации шага, ударов, взмахов и прыжков.
  * Специальная 4-фазная физика прыжков поринга (*RO Slime Hopping*) со сжатием, полётом по параболе, динамической тенью и растеканием при приземлении.

### 7. 💾 Надёжная система сохранений
* Автосохранение в `localStorage`.
* Встроенная система миграции сохранений с авто-нормализацией параметров и инвентаря.

## 🚀 Быстрый старт

### Требования
* [Node.js](https://nodejs.org/) версии 18 или новее
* Пакетный менеджер `npm` (или `pnpm` / `yarn`)

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/<your-username>/solo-mmo.git
   cd solo-mmo
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки**:
   ```bash
   npm run dev
   ```
   Откройте в браузере адрес `http://localhost:5173`.

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   Собранные оптимизированные файлы появятся в директории `dist/`.

5. **Предпросмотр продакшен-сборки**:
   ```bash
   npm run preview
   ```

## 📦 Управление релизами

В проект встроен автоматический скрипт простановки и публикации релизов.

### Варианты запуска:
* **Через Windows Batch** (в 1 клик):
  Дважды кликните по файлу `release.bat` в корне проекта.
* **Через npm-скрипты**:
  ```bash
  # Интерактивное меню выбора версии и описания:
  npm run release

  # Быстрые команды:
  npm run release:patch    # 1.0.0 -> 1.0.1 (исправления ошибок)
  npm run release:minor    # 1.0.0 -> 1.1.0 (новый контент, предметы, классы)
  npm run release:major    # 1.0.0 -> 2.0.0 (крупные обновления)
  ```

### Что делает скрипт автоматически:
1. Запускает проверку сборки и типов (`npm run build`), чтобы не допустить релиз сломанного кода.
2. Обновляет версию в `package.json` и `package-lock.json`.
3. Добавляет запись с датой и заметками в `CHANGELOG.md`.
4. Создаёт Git-коммит с сообщением `chore(release): vX.Y.Z`.
5. Создаёт аннотированный Git-тег `vX.Y.Z`.
6. Синхронизирует и пушит коммиты и теги на GitHub (`git push --follow-tags`).
7. (При наличии GitHub CLI `gh`) создаёт официальный GitHub Release.

## 🎮 Управление в игре

* **ЛКМ (Левый клик)**:
  * Клик по земле — перемещение персонажа в указанную точку.
  * Клик по монстру — выбор цели и начало атаки.
  * Клик по NPC — начало диалога или открытие меню.
* **Клавиши быстрого доступа**:
  * `C` — Окно характеристик (Stats)
  * `I` — Рюкзак и экипировка (Inventory)
  * `K` — Древо навыков (Skills)
  * `B` — Кузница и ковка (Blacksmith)
  * `Q` — Журнал квестов (Quests)
  * `M` — Карта мира (World Map)
  * `F` — Переключение режима авто-охоты (Camp Auto-Hunt)
  * `1`–`6` — Панель быстрого использования умений
